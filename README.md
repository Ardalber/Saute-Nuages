# ☁️ Saute-Nuages

## ▶ [JOUER MAINTENANT (ordinateur ou téléphone)](https://ardalber.github.io/Saute-Nuages/)

**Lien direct : https://ardalber.github.io/Saute-Nuages/**

**But du jeu : aspirer un maximum de boules !**
**Plume**, le petit oiseau jaune, saute de nuage en nuage. Passe près d'une boule : il l'aspire tout seul avec son bec.
Plus tu montes, plus le ciel passe au coucher de soleil puis à la nuit… et plus c'est dur !

## Installer sur le téléphone

1. Ouvre le lien ci-dessus dans **Chrome** (Android) ou **Safari** (iPhone).
2. Au lancement, choisis **📲 Installer sur le téléphone**.
   (Sinon, Chrome : menu ⋮ puis « Installer l'application » ; Safari : Partager puis « Sur l'écran d'accueil ».)
3. Le jeu apparaît sur l'écran d'accueil, avec son icône, et marche même sans internet.

## Comment jouer

- Plume rebondit tout seul sur les nuages.
- **Téléphone** : garde le doigt à gauche ou à droite de l'écran pour le diriger.
- **Ordinateur** : flèches gauche / droite (ou Q / D).
- Sortir d'un côté de l'écran fait revenir de l'autre.
- Boule de couleur = 1 point · Boule dorée = 5 points · Nuage bleu = il bouge · Nuage gris = il casse après un rebond · Ressort rouge = super saut.
- Si Plume tombe en bas de l'écran, c'est perdu. Ton record de boules est gardé.

## Fichiers

- `JOUER.html` : ouvre le jeu en un clic (sur ordinateur).
- `main.gd` : tout le jeu (Godot 4.7). Pour le modifier : dans Godot, Importer puis `project.godot`, puis F5.
- `docs/` : la version web publiée. Pour la mettre à jour : Projet, Exporter, Web (vers `docs/index.html`), puis pousser sur GitHub.
